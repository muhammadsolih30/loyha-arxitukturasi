# Loyiha Me'mori

## Qanday ishga tushirish

1. Bu papkani VS Code'da oching (`code .`)
2. Terminalda: `npm install`
3. Keyin: `npm run dev`
4. Terminalda chiqqan manzilni (odatda `http://localhost:5173`) brauzerda oching

## Fayllar

- `src/App.jsx` — asosiy dastur (rollar daraxti, tafsilotlar, eksport)
- `src/main.jsx` — React kirish nuqtasi
- `src/index.css` — asosiy uslub
- `index.html` — sahifa qobig'i
